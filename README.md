<h1>🚀AssessGen — Aptitude & Placement Assessment Generator</h1>
 

AssessGen is a customizable Aptitude & Placement Assessment Generator that allows students to create company-style aptitude tests using an AI-generated JSON file and practice them through a web-based assessment simulator.

Practice smarter. Prepare for company-style assessments. Get placement ready. 🎯

# 🛠️ **How to Use :**<br>

<h3>Step-1 — Open the Prompt</h3>

Download or open the Aptitude_Assessment_Prompt.pdf available in this repository.

The PDF contains the prompt required to generate a customized aptitude assessment.

<h3>Step-2 — Open ChatGPT</h3>

Open ChatGPT and paste the prompt provided in the PDF.

<h3>Step-3 — Enter Your Preferences</h3>

ChatGPT will ask you for assessment preferences such as:

Company/assessment style<br>
Number of questions<br>
Categories<br>
Difficulty level<br>
Time limit<br>
Other assessment preferences<br>

Provide your requirements according to your preparation goals.

<h3>Step-4 — Generate the JSON</h3>

ChatGPT will generate an assessment in JSON format.

Download the generated .json file.<br>

The JSON file contains information such as:<br>

Assessment Information<br>
├── Title<br>
├── Company / Assessment Style<br>
├── Duration<br>
├── Categories<br>
└── Questions<br>
    ├── Question<br>
    ├── Options<br>
    ├── Correct Answer<br>
    ├── Explanation<br>
    └── Category<br>

<h3>Step-5 — Open AssessGen</h3>

Open the deployed application:

🔗 https://assess-gen.vercel.app/

<h3>Step 6 — Upload JSON</h3>

Upload the .json file generated by ChatGPT.

AssessGen will automatically read the assessment and display information such as:

📌 Assessment title<br>
🔢 Number of questions<br>
⏱️ Duration<br>
📚 Number of categories<br>
🎯 Topics covered<br>

<h3>Step-7 — Customize Your Time</h3><br>

Before starting the assessment, customize the duration using the − / + controls.

This allows you to practice under different time constraints.

<h3>Step 8 — Start the Assessment</h3>

Click:

▶️ Start Assessment

Complete the assessment just like a real placement aptitude test.<br>

# **Aptitude_Assessment_Prompt.pdf**

This prompt is designed to be used with ChatGPT to generate the JSON assessment consumed by AssessGen.

The prompt is intentionally separated from the application so that users can:

Understand how assessments are generated
Customize their assessment requirements
Choose different difficulty levels
Select specific aptitude categories
Control the number of questions
Practice different company-style formats

JavaScript	Assessment logic and interaction
JSON	Assessment data format
ChatGPT / AI Prompt	Assessment generation
GitHub	Source code and prompt distribution
Vercel / Netlify	Static deployment

# 💡 **Why AssessGen?**

Students often practice random aptitude questions without knowing whether the questions match the type, difficulty, or structure of the assessments they are preparing for.

AssessGen provides a simple workflow for creating customized, company-style practice assessments.

Instead of:<br>
Random Questions<br>
      ↓<br>
   Practice<br>
      ↓<br>
    Repeat<br>
