Every question must be:
* Original
* Placement level

# JSON SCHEMA (STRICT)
The generated JSON MUST strictly follow this schema.
Never rename any field.
Never add extra fields.

## Root Object
Use EXACTLY these keys:
* "assessment_title"
* "company_name"
* "duration_minutes"
* "questions"
No additional root-level fields are allowed.

## Question Object
Every question MUST contain EXACTLY these keys:
* "id"
* "category"
* "difficulty"
* "question"
* "options"
* "correct_answer"
* "explanation"
No additional fields are allowed.

# FIELD RULES
## assessment_title
String

## company_name
String

## duration_minutes
Integer
Automatically calculate a realistic duration based on the total number of questions.

## questions
Array

# QUESTION FIELD RULES
## id
* Integer
* Starts at 1
* Sequential
* Unique

## category
String
Must match one of the selected categories.

## difficulty
Must be EXACTLY one of:
* "Easy"
* "Medium"
* "Hard"
No other values are allowed.
Capitalization must match exactly.

## question
String

## options
* Array
* Exactly 4 options
* Plain text strings only
* No numbering
* No prefixes like:
 * A.
 * B.
 * C.
 * D.
 * 1.
 * 2.
 * 3.
 * 4.
* No duplicate options within a question.

## correct_answer
* Must be a string.
* Must exactly match one of the four option strings.
* Copy the option text character-for-character.
* Never use option indexes.
* Never use A/B/C/D.

## explanation
String
Briefly explain why the answer is correct.

# VALIDATION RULES
Before generating the downloadable JSON file, validate that:
* JSON is syntactically valid.
* No trailing commas exist.
* Every bracket is correctly closed.
* Every required field is present.
* No extra fields exist.
* IDs are sequential.
* IDs are unique.
* Every question has exactly four options.
* Every correct_answer exactly matches one option.
* No duplicate questions exist.
* No duplicate options exist within the same question.
* The JSON parses successfully without errors.
If validation fails, automatically correct the issues before creating the downloadable file.

Do NOT print the JSON inside the chat.

1. Generate the complete assessment.
2. Validate the JSON.
3. Create a downloadable `.json` file.
Use the following filename format:
`<CompanyName>_<Category>_<NumberOfQuestions>.json`
Examples:
* TCS_NQT_Quantitative_Aptitude_20.json
* Accenture_Mixed_Assessment_50.json
* Infosys_Logical_Reasoning_30.json
After generating the file, simply provide the downloadable JSON file.
Do not display the JSON unless I explicitly request it.

The generated JSON file must be immediately importable into my aptitude assessment platform without requiring any manual modifications.
